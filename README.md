# Café Aroma ☕

Um website fictício para um café de especialidade, desenvolvido em HTML, CSS e JavaScript puro.

Este projeto foi feito enquanto estava a aprender desenvolvimento web — a ideia foi criar um site completo para praticar a estruturação de páginas, estilos e interações com JavaScript.

## O que faz

- Apresenta a página inicial do Café Aroma
- Mostra informações sobre o café e o seu horário
- Permite consultar o menu completo
- Organiza o menu por categorias: Bebidas, Entradas e Salgados e Doces
- Permite filtrar as diferentes categorias do menu
- Inclui uma opção para reservar uma mesa através do WhatsApp
- Apresenta contactos, redes sociais e localização

## Como experimentar

Só precisas de abrir o `index.html` no browser — não é necessário instalar nada.

👉 [Ver o site ao vivo](https://bosslxk.github.io/Cafe-Aroma/)

## Tecnologias

- HTML5
- CSS3 (animações e media queries para mobile)
- JavaScript (vanilla, sem bibliotecas)
